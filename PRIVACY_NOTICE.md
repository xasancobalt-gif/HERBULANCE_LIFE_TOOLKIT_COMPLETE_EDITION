# Privacy Notice

**Effective date: 15 November 2026**

## Summary

The offline HERBULANCE LIFE TOOLKIT does not require an account and contains no analytics, advertising SDK, tracking pixel, cloud database or required remote service.

## Data stored locally

If the browser permits local storage, the toolkit can save:

- welcome status and colour theme;
- recent reading and history;
- per-volume progress and completed chapters;
- bookmarks;
- personal learning goals.

These records stay in the browser profile on the device. The application does not transmit them to HERBULANCE or a server.

## Export and import

The User can export local learning data to a file and import it later. Exported files can reveal reading interests, goals and bookmarks. Store and share them carefully. Import only a file obtained from a trusted source.

## Deletion

Use Reset Local Data in the toolkit or clear the browser's local/site data. Deleting the extracted product folder does not necessarily clear browser storage, and clearing browser data can remove progress.

## Shared devices

Anyone with access to the same device and browser profile may be able to view local records. Use a separate operating-system/browser profile where privacy matters.

## External links

Reference and resource links are not opened automatically. If the User chooses to open an external website, the browser connects to that third party and its privacy terms apply. Core reading and search do not require those sites.

## Children and sensitive data

The toolkit is not designed to collect personal information from children. Do not place names, diagnoses, contact details or other sensitive personal information in the goals field or exported learning file.

## Changes and contact

Privacy changes should be documented in `VERSION_HISTORY.md`. For seller or rights-holder contact details, use the purchase record or official storefront; none was supplied for embedding in this edition.
