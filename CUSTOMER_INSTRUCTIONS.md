# Customer Instructions

## 1. Open the toolkit

1. Download `HERBULANCE_LIFE_TOOLKIT_COMPLETE_EDITION.zip`.
2. Extract or unzip it completely.
3. Keep all extracted files and folders together.
4. Double-click `HERBULANCE_LIFE_TOOLKIT.html`. If your system asks which app to use, choose a current web browser.

`index.html` is an equivalent entry file.

## 2. Browser guidance

A current Chrome, Edge, Firefox or Safari browser is recommended. JavaScript must be enabled. The tested release used Chromium 141. The toolkit is a set of local static files; no browser extension or installer is needed.

Some browsers apply stricter privacy rules to local files. If saved progress does not persist after closing the browser, keep the extracted folder in a stable location, avoid private/incognito mode, and use the Export function regularly.

## 3. Use the toolkit

- **Library:** browse all 30 volumes.
- **Seven life systems / stages:** explore cross-book pathways.
- **Search:** search all locally indexed chapters, tools, quizzes, glossary records and references.
- **Quick Action Centre:** open practical tools by goal.
- **Learning Centre:** access quizzes, worksheets, recipes, resources and other study materials.
- **Personal learning:** review recent items, bookmarks, progress and goals.
- **Independent books:** open any `books/book-NN/index.html` directly. Use the floating **LIFE TOOLKIT** button to return to the collection and manage local progress.

## 4. Save and back up progress

Progress, bookmarks, history and goals are saved in the browser's local storage on your device. They are not sent to HERBULANCE.

Use **Export learning data** in the Personal Learning area to download a backup. Use **Import learning data** to restore a valid export. An import replaces the matching local toolkit data, so export the current state first if it matters.

Clearing site/browser data, switching browser profiles, moving to another browser or using private mode can remove or isolate saved records.

## 5. Print

Use the toolkit's Print control or your browser's Print command. Choose **Save as PDF** if available. Print layouts can vary by browser and printer.

## 6. Internet use

Core reading and search work offline. Reference pages and other external links require internet only if you choose to open them. External sites have their own privacy and content policies.

## 7. Troubleshooting

- **Blank or unstyled page:** confirm the ZIP was extracted and the `assets` and `books` folders remain beside the entry file.
- **A single book will not open:** return to the root entry file and open it from the library. Do not rename nested folders.
- **Progress is missing:** check that you are using the same browser profile and the same extracted file location; restore an export if available.
- **Search has no result:** try fewer words or a broader term. Search snippets are not medical advice; open the full chapter for context.
- **Need a clean start:** export first, then use Reset Local Data.

## 8. Safety

Never delay emergency care to search this product. Call your local emergency number for urgent symptoms. Consult a qualified professional for personal diagnosis, treatment, medicines, supplements, pregnancy, childhood, older-age care, allergies or chronic disease.
