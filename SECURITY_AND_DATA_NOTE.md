# Security and Data Note

- The core product is static HTML, CSS, JavaScript, images and data files.
- It requires no server, database, account, analytics or tracking service.
- No required remote script, stylesheet, font, image or media resource remains.
- External reference links are opened only when selected by the User.
- Learning data is stored in browser local storage and can be exported/imported.
- Imported learning files should be treated as untrusted personal data and accepted only from a trusted source.
- The application does not claim protection against a compromised device, browser extension, altered package or malicious third-party website.
- Compare files with `MANIFEST.sha256` if integrity is in doubt.
