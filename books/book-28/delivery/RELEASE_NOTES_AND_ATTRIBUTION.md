# Release Notes & Source/Asset Attribution Manifest

## Version 1.0 — 2026

### Contents included

- 22 chapters across five parts.
- Front matter: cover, title, brand introduction, educational-use notice, medical disclaimer, usage guidance, audience, outcomes, contents, roadmap and urgent-warning guide.
- Original labelled educational diagrams: ear anatomy, cochlea/hair cell schematic, vestibular system, ear hygiene, device comparison and illustrative audiogram.
- Learning tools: anatomy explorer, vestibular explorer, audiogram explorer, noise-dose learning lab, scenario-learning activity, flashcards, 13 printable worksheets, glossary and FAQ.
- Interactive features: search, bookmarks, completion progress, dark/light mode, print views, responsive navigation and local storage.
- Evidence Centre with selected sources by topic and an exportable reference list.

### Design and technology

- Premium HERBULANCE editorial identity: warm paper, deep forest, clay and gold; serif display type with sans-serif interface type.
- System font stack for offline resilience.
- Lucide icon set (ISC licence) for interface icons.
- React + Vite + Tailwind CSS compiled into a single production HTML file.

### Release limitations

- No named clinical review and sign-off.
- Public-health guidance and service access vary by country.
- Some external citation pages may change after release.
- Manual screen-reader, cross-browser and print-render testing remains outstanding.
- Local browser storage is not a medical record and may be erased.

## Source & asset attribution manifest

### Original assets

The following were created originally for this edition as simplified educational schematics, using HTML, CSS and inline SVG:

- Ear anatomy cross-section
- Cochlear turn and hair-cell schematic
- Vestibular labyrinth schematic
- Ear-hygiene/self-cleaning illustration
- Device comparison schematic
- Illustrative audiograms
- Hearing-process and lifespan learning graphics
- Brand mark and cover treatment

These diagrams are educational illustrations, not clinical photographs or diagnostic images. They are not to scale and should not be used for surgical or diagnostic purposes.

### Fonts

No remote or proprietary web font is required. The interface uses a local system font stack, beginning with Iowan Old Style/Palatino/Georgia for editorial serif text and Inter/Avenir Next/Segoe UI/Arial for interface text.

### Interface icons

Lucide (https://lucide.dev), ISC licence. Icons are embedded with the application at build time; no external icon CDN is required.

### Evidence sources

The Evidence Centre and in-book claims draw on selected material from the World Health Organization; the US National Institute on Deafness and Other Communication Disorders; the US National Institutes of Health; the UK National Health Service; the US Centers for Disease Control and Prevention/National Institute for Occupational Safety and Health; the American Academy of Otolaryngology–Head and Neck Surgery Foundation; the American Academy of Audiology; Cochrane; the Bárány Society; the Joint Committee on Infant Hearing; and the US Food and Drug Administration, among other cited professional sources.

Reference titles, organisations, dates and URLs are listed in the book’s Evidence Centre. Third-party material remains the property of its respective organisation. Listing a source does not imply endorsement of this book by that organisation.

No stock photograph is used as a substitute for required educational diagrams. No external image is loaded at runtime.
