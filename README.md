# HERBULANCE LIFE TOOLKIT — The Complete Digital Edition

A unified, offline-first collection of 30 interactive HERBULANCE health, food, wellbeing and life-education volumes.

## Edition 1.0.0

- 30 independently accessible volumes
- 1,541 canonical chapters
- 3,969 offline search records
- 1,346 glossary records
- 654 consolidated references
- Seven life systems and seven life stages
- Local progress, bookmarks, history, goals, export and import
- No account, server, database, analytics or required internet connection

## Run locally

Clone or download the repository, keep its directory structure intact, and open:

```text
HERBULANCE_LIFE_TOOLKIT.html
```

`index.html` is an equivalent entry point. Current Chrome, Edge, Firefox or Safari is recommended. No build step is required.

The complete customer ZIP and checksum are published under **Releases**.
